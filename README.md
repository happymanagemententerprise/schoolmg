# Northstar Academy

A dependency-free front-end prototype for a school management system. Open `index.html` in a browser to explore the role-based dashboard.

The prototype includes:

- Administrator, class teacher, subject teacher, student, and parent viewing modes.
- Term switching and third-term report presentation.
- The promotion rule: Mathematics and English above 50%, plus at least three other subjects above 50%.
- Searchable student progress table with report drawer and promotion status.
- Attendance summary, key dates, assignments entry point, and school report navigation.

This is currently a client-side prototype; authentication, spreadsheet parsing, persistence, and server-side permissions still need to be connected to a backend.
